# AksharaAI Website

A responsive, static introduction website for the proposed AksharaAI Telugu reading assessment project.

## Project status
Idea and concept stage. This website describes planned features; it does not claim that the AI system is already built or operational.

## Files
- `index.html` — website content and structure
- `style.css` — responsive visual design
- `script.js` — mobile navigation and current year

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `aksharaai`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The expected URL format is `https://saikrish0204.github.io/aksharaai/`.

## Before submitting
- Open the published link on a phone and computer.
- Check that all sections load and the navigation works.
- Do not add personal phone numbers or email addresses unless you intend them to be public.
- Keep the idea-stage/prototype-planned wording accurate.
- Confirm TISC's applicant and guardian-consent requirements directly with the organisers.
